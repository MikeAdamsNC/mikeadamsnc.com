# MikeAdamsNC brand

The decided pieces of the brand. `BRAND-BRIEF.md` is how we got here; this file is
what the site uses.

## Colors (decided 2026-10-22)

One palette: "Coastal, Red Spark." Ocean first; NC State and Hurricanes red only as a
small spark.

| Name | Hex | Job |
|---|---|---|
| Foam | `#F2F6F6` | Page background |
| White | `#FFFFFF` | Cards and raised surfaces |
| Deep ink | `#0B1620` | Text |
| Muted | `#56676F` | Secondary text |
| Line | `#D7E2E3` | Borders and dividers |
| Deep water | `#0B6E7A` | The main color: buttons, links, the "nc" in the name, headline accents, the idea band |
| Float aqua | `#7FD6CF` | Supporting accent: card stripes, status pills, soft highlights |
| Wolfpack red | `#CC0000` | Spark only: the "building right now" dot and other tiny live signals. Never a button, band or large area. |

### Reserve color

| Name | Hex | Job |
|---|---|---|
| Panther blue | `#0085CA` | Not part of the everyday look. Kept in the system for when a second strong blue is truly needed (a chart series, a Panthers-related project, a one-off moment). Never next to Deep water as an equal; never replaces it. |

Tried and set aside: Panther blue on the main button, on the name, or on the idea band.
Each felt forced beside Deep water.
